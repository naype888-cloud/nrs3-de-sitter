The de Sitter horizon of the three-torus

Λ = 3π / (2 ℓ² N ln 2),   N = dy·dz  ⟺  S = 2N ln 2,   A = 12π/Λ = a²·2N,   a² = 4ℓ² ln 2

The cut of the torus has N = dy·dz faces and two sheets (the plane and the seam), so its entropy is S = 2N ln 2. That entropy fixes the constant of a de Sitter horizon. Closing the axes halves Λ at the same face. Every number is tied to the Lean lemma that proves it.
